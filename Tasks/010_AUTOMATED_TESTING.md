# TASK-010 — Automated Unreal Testing

## Objective
Give agents the ability to execute and observe Unreal tests rather than merely construct assets.

## Target capabilities
Automation Framework tests, PIE start/stop, runtime actor/property inspection, controlled input where supported, log collection, viewport capture, and later multiplayer PIE/dedicated-server tests.

## Acceptance criteria
A deterministic Tool Lab test launches, observes runtime state, terminates cleanly and returns a pass/fail result without human editor manipulation.
