# TASK-012 — First Fully Autonomous Unreal Proof

## Objective
Prove the factory works end-to-end with no manual editor construction.

## Test
Using Tool Lab only, the agent must create a disposable Blueprint actor with a visible component and configurable property, place it in a test map, compile/save, run PIE, verify the runtime value, stop PIE, collect logs and report all changed assets.

Execute the same specification once with Codex and once with Claude.

## Acceptance criteria
Both agents complete and verify the task without the human dragging nodes, changing properties or placing actors manually.
